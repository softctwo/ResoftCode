Publish the CLI under `@chinaresoft/resoftcode` and ship the canonical `resoftcode` command. `resoft`, `kilo`, and `kilocode` remain backward-compatible aliases.

Install:

```sh
npm install -g @chinaresoft/resoftcode
```

After install, `resoftcode`, `resoft`, `kilo`, and `kilocode` all launch the same binary.

First internal release (`v0.1.0`) of the Resoft CodingAgent CLI for
the regulatory reporting program. This bundles every commit from the
`@chinaresoft/resoftcode` rebrand through the V1 MCP server work:

- Brand: canonical `@chinaresoft/resoftcode` package; `resoftcode`,
  `resoft`, `kilo`, and `kilocode` remain installed as backward-
  compatible aliases.
- `resoft init`: scaffolds the V1 regulatory reporting starter pack
  (9 specialized agents, a workflow command, a `kilo.jsonc` pinned
  to a provider preset). `--with-mcp` merges the mock SQL MCP
  server block into `kilo.jsonc` so the data-aware agents
  (quality-analyst, etl-developer, data-tester, data-analyst)
  can call `mock_sql_query` and `mock_csv_list` out of the box.
- `resoft validate`: checks an installed starter pack against the
  V1 contract (files present, JSONC parses, active model resolves,
  enabled_providers match, subagent_model tracks, agents valid,
  apiKey env set when `--strict-env` is on).
- `resoft start`: prints the real launch command for a regulatory
  reporting delivery loop (verified end-to-end against the real
  DeepSeek cloud API; produces `output/G01_2025Q4.csv` for the
  bundled regulatory demo dataset).
- `resoft providers`: lists the 7 built-in provider presets
  (resoft / deepseek / openai / moonshot / zhipu / qwen / ollama)
  plus user-global and project-local custom providers from
  `resoft-providers.jsonc`.
- Agent tool allowlists: every V1 agent declares an explicit
  deny-by-default `tools:` allowlist (read-only for analysis
  agents, read+execute for exploration, read+write for
  development, webfetch scoped to `regulation-interpreter`).
- VS Code bridge: when `kilo-code.new.resoftBridge.enabled` is
  on, the extension prefers a system-installed `resoftcode` over
  the bundled `kilo` binary, with `RESOFT_CLI=1` in the spawned
  process so `~/.resoft` stays isolated.

Install:

```sh
npm install -g @chinaresoft/resoftcode@0.1.0
resoftcode --version
resoftcode resoft providers
resoftcode resoft init --with-mcp --provider deepseek --dir ./reg-reporting
resoftcode resoft validate --dir ./reg-reporting
resoftcode resoft start --dry-run --dir ./reg-reporting
```

Verify:

```sh
# In a fresh project directory:
resoftcode resoft init --with-mcp --provider deepseek
DEEPSEEK_API_KEY=sk-... resoftcode run \
  --command regulatory-reporting-v1 \
  --model deepseek/deepseek-v4-pro \
  --auto --format json
# expect: output/G01_2025Q4.csv with 6 data rows + 1 header.
```
